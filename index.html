The loop

Skills move around the shop.

  1. Repertoire → CompositionEvery named skill goes into the catalogue the router picks from.
  2. Reliability → CompositionHardened checkpoints replace the ones in the catalogue.
  3. Twin → ReliabilityVerified scenes from the twin become evaluation cases.
  4. Twin ↔ CompositionThe manipulation view runs the same pipeline against the twin first.
  5. Real robot → TwinRobot state syncs back so the twin stays honest.
